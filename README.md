# PoE Map Crafter

Windows-приложение (Python) для автоматического крафта карт T16 в Path of Exile 1 через визуальное распознавание интерфейса (OpenCV + захват экрана). Без чтения памяти игры и без обхода античита.

## Требования

- Windows 10/11
- Python 3.10+
- Path of Exile в оконном или безрамочном режиме

## Установка

```powershell
cd C:\Users\Nik\poe-map-crafter
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

При первом **«Старт»** программа наводит курсор на каждый слот инвентаря, читает всплывающую подсказку (**Tesseract OCR** через `pytesseract`) и запоминает предметы и размер стопок. Не двигайте мышь во время этой фазы.

### Tesseract OCR (Windows)

1. Скачайте установщик: [UB-Mannheim Tesseract](https://github.com/UB-Mannheim/tesseract/wiki).
2. Установите в `C:\Program Files\Tesseract-OCR\` (по умолчанию), отметьте языки **English** и при русском клиенте **Russian**.
3. `pip install pytesseract` (уже в `requirements.txt`).

Если Tesseract не установлен, орбы всё равно ищутся по изображению ячейки, но названия и точный размер стопки могут не определиться.

## Запуск

```powershell
python main.py
```

## Подготовка в игре

1. Откройте вкладку сундука с картами T16.
2. Откройте инвентарь персонажа: **Orb of Scouring** и **Orb of Alchemy**.
3. Введите regex в строку поиска сундука (PoE подсветит подходящие карты).
4. Сделайте окно PoE активным и нажмите **Start** в приложении.

## Горячая клавиша

По умолчанию **F12** — немедленная остановка (настраивается в `config/default_config.json`).

## Настройка областей UI

Координаты сундука, инвентаря и строки поиска задаются долями клиентской области окна игры в `config/default_config.json` (`left`, `top`, `width`, `height`, сетка `columns` × `rows`).

Если автопоиск валюты срабатывает ненадёжно, укажите слоты явно:

```json
"currency_slots": {
  "scouring": [0, 0],
  "alchemy": [1, 0]
}
```

Формат: `[column, row]` в сетке инвентаря. Если слоты не заданы, орбы ищутся автоматически при сканировании инвентаря.

Секция `inventory_probe` in config: задержка наведения и область захвата подсказки относительно курсора (`tooltip_offset_*`, `tooltip_width`, `tooltip_height`). Если имена предметов читаются криво, подстройте смещения под свой UI.

### Калибровка сетки инвентаря / сундука

Если курсор при сканировании не попадает в слоты:

1. Откройте сундук и инвентарь в PoE.
2. Нажмите **«Скриншот сетки»** — в папке `debug/` появится картинка с жёлтой (сундук) и зелёной (инвентарь) сеткой.
3. **Инвентарь F8→F9** — наведите на **центр** ячейки `[0,0]`, нажмите **F8**, затем **центр** ячейки `[11,4]` (правый нижний угол инвентаря 12×5), **F9**.
4. Аналогично **Сундук F6→F7** для сетки `[0,0]` → `[11,11]`.

Координаты сохраняются в `config/default_config.json` автоматически.

## Пороги распознавания

Параметры серой/подсвеченной карты и цветов орбов — в секции `detection` того же файла. Подстройте под ваш яркостной профиль и фильтр сундука.

## Архитектура

| Модуль | Назначение |
|--------|------------|
| `screen_detector` | Окно игры, проверка regex в поиске, инициализация |
| `stash_scanner` | Состояние ячеек сундука |
| `inventory_scanner` | Поиск валюты |
| `currency_controller` | Scouring → Alchemy |
| `crafting_engine` | Основной цикл крафта |
| `safety_controller` | Фокус окна, Stop, F12 |
| `statistics` | Счётчики и итоги |
| `action_delay` | Случайные задержки и разброс координат клика |
| `gui` | Интерфейс Start/Stop, статистика, лог |

## Ограничения MVP

- Области UI могут потребовать калибровки под разрешение и масштаб UI.
- Распознавание серых карт основано на насыщенности HSV; сложные фильтры могут потребовать подстройки `detection`.
- Приложение управляет мышью: не двигайте курсор в угол экрана (PyAutoGUI failsafe), пока идёт работа.

## Предупреждение

Автоматизация ввода может нарушать правила игры. Используйте на свой риск.
